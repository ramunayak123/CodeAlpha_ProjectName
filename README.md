# CodeAlpha Internship Projects

Welcome to my **CodeAlpha Full Stack Development Internship Projects** repository! This repository contains two projects developed as part of my internship to improve my web development and programming skills.

## 🚀 Projects

### Task 1: Simple E-commerce Store – ShopEase

**Description:**

A simple e-commerce website that allows users to browse products, view product details, add products to a shopping cart, and manage their shopping experience.

**Technologies Used:**
- HTML
- CSS
- JavaScript
- Django (Python)
- SQLite

**Features:**
- Product listings
- Product details
- Shopping cart
- User registration and login
- Order processing
- Responsive user interface

**Project File:** `shopease-–-simple-e-commerce-store.zip`

### Task 2: Mini Social Media Platform

**Description:**

A mini social media application that allows users to create profiles, share posts, interact with other users, and connect through social features.

**Technologies Used:**
- HTML
- CSS
- JavaScript
- Django (Python)
- SQLite

**Features:**
- User registration and login
- User profiles
- Create and manage posts
- Like posts
- Comment on posts
- Follow and unfollow users
- Social interaction features

**Project File:** `mini-social-media-platform.zip`
